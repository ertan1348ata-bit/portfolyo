# Kişisel Portfolyo Sitesi

HTML, CSS ve JavaScript ile yapılmış, koyu/açık tema destekli, mobil uyumlu tek sayfalık portfolyo sitesi.

## Özellikler
- Mobil uyumlu tasarım
- Koyu / açık tema (tercih hatırlanır)
- Hakkımda, Projeler ve İletişim bölümleri
- Sıfır bağımlılık, derleme gerekmez

## Çalıştırma
`index.html` dosyasını tarayıcıda açmanız yeterli.

## Özelleştirme
- `index.html` içindeki "Adınız Soyadınız", "KULLANICI_ADINIZ" ve proje kartlarını kendi bilgilerinizle değiştirin.
- Renkler `style.css` dosyasının başındaki `:root` değişkenlerindedir.

## Yayınlama (GitHub Pages)
Depo **Settings → Pages → Branch: main / root** ayarıyla ücretsiz yayınlanır.

## Notlar
Bu proje yapay zeka yardımıyla geliştirilmiştir.
